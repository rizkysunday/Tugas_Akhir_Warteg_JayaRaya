1. Fitur Dark Mode (LocalStorage) adalah fitur yang menyediakan tombol "Mode Gelap"/"Mode Terang" di navbar untuk mengganti tema tampilan website, dimana state tema yang dipilih akan tersimpan secara permanen di localStorage sehingga tidak berubah saat halaman di-refresh.

2. Fitur Pengelolaan Stok merupakan fitur pada tombol "Beli" di setiap card menu yang berfungsi mengurangi angka stok secara real-time saat diklik, memunculkan alert konfirmasi "Berhasil membeli [nama menu]", dan secara otomatis menonaktifkan tombol serta mengubah teks menjadi "Habis" ketika stok mencapai angka 0.

3. Fitur Wishlist (SessionStorage & Modal) adalah fitur yang memungkinkan pengguna menyimpan menu favorit ke dalam sessionStorage melalui tombol "Wishlist" di setiap card, dengan badge angka pada tombol navbar yang terupdate otomatis sesuai jumlah item, serta modal yang menampilkan daftar item tersimpan dilengkapi tombol hapus per item dan tombol "Kosongkan" untuk menghapus semua item.
